## Сейчас в комплекте
- `app.html` — интерфейс приложения, рассчитанный на desktop/mobile.
- `manifest.webmanifest`, `sw.js`, `assets/` — установка как PWA и кэширование оболочки.
- `windows-installer.iss` — заготовка сценария Inno Setup; требует Inno Setup и Windows WebView2.

## Важное
Это автономный прототип с локальными демоданными. Новые заседания и задачи, а также отправленные демонстрационные сообщения сохраняются в браузере на текущем устройстве. Общих учетных записей, сервера и синхронизации команды пока нет. Нельзя использовать для реальных судебных дел без серверной разработки, контроля доступа, резервных копий и аудита.

Для установки PWA разместите содержимое этой папки на HTTPS-хостинге. Откройте адрес в Edge/Chrome на компьютере или Safari на iPhone и выберите «Установить приложение» / «На экран Домой». Открытие через `file://` не включает PWA и offline cache.

Для настоящего Windows EXE требуется включить в установщик WebView2 host; сценарий `windows-installer.iss` предполагает `ENote.exe`, который еще надо создать и проверить. Android APK требует Android SDK и подписи; iOS IPA требует macOS/Xcode, Apple signing и профиля распространения. Эти сборки не выдаются за готовые в этом наборе.

## Основные следующие этапы продукта
1. API-сервер, PostgreSQL, аутентификация и роли.
2. Совместная работа, история/корзина с правами и автоматическое удаление через 24 часа.
3. Настоящие чаты, отправка вложений, аудио и видео через защищенное хранилище и realtime-сервис.
4. Импорт, личные задачи, комментарии, журнал аудита, погода/новости и админка.
5. Native packaging, тестирование и публикация Windows/Android/iOS.
